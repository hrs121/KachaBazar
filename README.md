# 🛒 KachaBazar E-Commerce Platform

## Overview

**KachaBazar** is an e-commerce platform designed to connect customers directly with farmers, eliminating middlemen and enabling fair, transparent, and efficient grocery purchasing. The platform supports both **B2B** (bulk purchases directly from farmers) and **B2C** (direct customer orders from warehouse stock).

---

## 🌟 Features

- 📦 Order fresh groceries directly from farmers (B2B)
- 🏪 Purchase daily grocery items from platform-managed warehouse stock (B2C)
- 🚛 Seamless logistics for delivery
- 💳 Online payments with commission-based revenue model
- 🧑‍🌾 Farmer dashboard for managing inventory and orders
- 📈 Admin analytics for inventory, revenue, and logistics tracking

---

## 🧱 Tech Stack

| Layer      | Tech          |
|------------|---------------|
| Frontend   | Next.js (React-based) |
| Backend    | Node.js + Express |
| Database   | MongoDB (can be replaced with PostgreSQL/MySQL) |
| Auth       | JWT (JSON Web Tokens)
